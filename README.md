# Front-End Engineering & Real-World Case Studies

Una raccolta curata di architetture, moduli logici e progetti pratici sviluppati durante il mio percorso avanzato in **TypeScript, React e Next.js**.

A differenza delle esercitazioni teoriche di base, questo repository è focalizzato su ipotetici **scenari reali**, **qualità del codice**, **immutabilità funzionale**, **testing automatizzato** e **documentazione tecnica (PRD)**.

---

## 🛠️ Stack Tecnologico Principale

- **Linguaggi:** TypeScript, JavaScript (ESModules)
- **Framework & Librerie:** React, Next.js
- **Testing & Tooling:** Vitest, ESLint, Git, Vite
- **Pratiche:** Functional Programming, Immutabilità, Unioni Discriminate, Safe Navigation

---

## 🎯 Standard di Sviluppo
Tutti i moduli contenuti in questo repository rispettano i seguenti vincoli di qualità:
1. **Type Safety rigorosa:** Nessun uso di `any`, tipizzazione esplicita di strutture dati e gestione di `noUncheckedIndexedAccess`.
2. **Immutabilità:** Trasformazioni di array e oggetti gestite tramite spread operator e metodi funzionali (`map`, `filter`, `reduce`).
3. **Unit Testing:** Suite di test automatizzati con Vitest per ogni funzione di business logic.
4. **Allineamento con i Requisiti:** Ogni feature è tracciata da un Product Requirements Document (PRD) di riferimento.
